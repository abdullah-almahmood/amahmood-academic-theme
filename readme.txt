A block theme (full site editing) for an academic research portfolio.

== Install or update ==

1. Appearance -> Themes -> Add New -> Upload Theme -> aam-academic.zip.
   If already installed, choose "Replace active with uploaded".
2. Settings -> Permalinks -> Save. Clear any cache.

If the front page still shows old content: Appearance -> Editor ->
Templates -> Front Page -> three-dot menu -> Reset.

== Editing ==

Settings -> Site content (AAM): contact details including GitHub, CV file,
portrait, certificates and gallery images, and the main blocks of copy.
